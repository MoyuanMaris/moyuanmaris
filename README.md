# 墨渊Maris小站

纯静态博客：没有构建步骤、没有数据库、没有第三方依赖。
文章就是 `posts/` 目录下的 `.txt` 文件，用记事本也能改。

线上地址：<https://moyuanmaris.pages.dev>（Cloudflare Pages 盯着本仓库的 `main` 分支，推送即部署）

## 目录

```
index.html          首页（文章列表 / 详情 / 标签 / 关于）
css/style.css       全站主题（颜色都在顶部的变量里）
js/
  config.js         ★ 站点配置：站名、头像、导航、页脚、关于页
  markdown.js       自带的小 Markdown 渲染器（无外部依赖、无 CDN）
  store.js          文章读取层
  app.js            路由与页面渲染
  fx.js             背景特效：光晕、鼠标拖尾的几何图形
posts/
  index.json        ★ 文章清单，新增文章要在这里登记文件名
  _template.txt     ★ 新文章模板（下划线开头的文件不会出现在列表里）
  images/           文章配图
  *.txt             文章本体
assets/             头像等静态资源
```

## 写一篇新文章

1. 复制 `posts/_template.txt`，重命名为比如 `2026-02-01-my-post.txt`；
2. 开头写信息块，用一行 `---` 和正文分隔：

   ```
   标题: 我的新文章
   日期: 2026-02-01
   标签: 随笔, 生活
   摘要: 首页列表里显示的一行简介（可省略）
   封面: images/cover.jpg（可省略）
   置顶: 否
   ---

   正文用 Markdown 写……
   ```

3. 把文件名加进 `posts/index.json` 的 `posts` 数组；
4. 推送后 Cloudflare 自动重新部署。

信息块支持中英文键名（`title` / `date` / `tags` / `summary` / `cover` / `pinned`），整块也可以省略——
标题会取正文里第一个 `# 一级标题`，日期按文件名排序。

## 支持哪些写法

标题、粗体、斜体、删除线、`==高亮==`、行内代码、代码块、有序 / 无序 / 嵌套列表、待办清单、
引用、表格（含对齐）、分割线、链接、图片（带图注 `![说明](图.png "图注")`）、裸网址自动链接、
B 站视频（单独一行写 `@bilibili BV号`）。

> 这个仓库只放站点本身。写作用的「写作台」和本地预览工具都在本机的 `studio/` 文件夹里，
> 不会上传到仓库。
