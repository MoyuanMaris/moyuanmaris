## 标题

`#` 到 `######` 表示一到六级标题，`#` 后面记得留一个空格。

## 文字样式

**粗体**、*斜体*、~~删除线~~、==高亮==、`行内代码`。

## 列表

- 无序列表用 `-`、`*` 或 `+`
- 嵌套只要缩进两个空格

  - 再深一层也可以

待办清单：

- [x] 已经做完的事
- [ ] 还没做的事

## 引用

> 一个人只拥有此生此世是不够的，他还应该拥有诗意的世界。
>
> 引用里也可以有 **粗体** 和 `代码`。

## 代码

行内用反引号包起来，例如 `npm run dev`。

多行用三个反引号，并标注语言：

```python
def greet(name):
    return f"你好，{name}"
```

```css
.leaf {
  color: #4c8f41;
  border-radius: 16px;
}
```

## 表格

| 语法 | 效果 | 备注 |
| --- | --- | --- |
| `**文字**` | **加粗** | — |
| `*文字*` | *斜体* | — |
| `[文字](链接)` | 链接 | 新窗口打开 |

对齐方式由分隔行决定：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| a | b | c |
| 100 | 200 | 300 |

## 链接

- 行内链接：[搜索一下](https://www.bing.com)
- 直接写的网址也会自动变成链接：https://example.com

## 引用 B 站视频

单独占一行，写下面任意一种，就会变成能直接播放的视频（自适应宽度）：

```text
@bilibili BV1xx411c7mD                          BV 号
@bilibili BV1xx411c7mD?p=2                      第 2 P
@bilibili BV1xx411c7mD&t=60                     从第 60 秒开始
@bilibili av170001                              老的 av 号
https://www.bilibili.com/video/BV1xx411c7mD     整条视频链接
<iframe src="//player.bilibili.com/player.html?bvid=BV1xx411c7mD"></iframe>
```

只有整行都是视频号或链接时才会嵌入；写在句子中间仍然只是普通文字。
